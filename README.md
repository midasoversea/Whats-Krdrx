# Whats-Krdrx

A privacy-conscious Android companion utility for WhatsApp.

## Initial scope
- WhatsApp-inspired Light/Dark UI with one-tap theme toggle.
- Status media browser (user-granted access only).
- Notification archive foundation (explicit user-granted notification access).

Package: `com.whats.krdrx`

This app does not modify WhatsApp, access its private database, or automate message sending. Notification-based recovery is limited to content Android exposes in notifications.
